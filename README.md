# Streitschlichter Webseite

Eine moderne, einseitige Website für das Streitschlichter-Team. Die Seite stellt den Auftrag, das Team, den Ablauf einer Streitschlichtung sowie häufig gestellte Fragen vor und bietet ein Kontaktformular.

## Inhalte
- Hero-Bereich mit Call-to-Action
- Abschnitt zu Auftrag und Grundsätzen
- Teamvorstellung mit Kartenlayout
- Ablauf als Timeline
- FAQ über aufklappbare Fragen
- Kontaktformular mit Netlify-Forms-Anbindung und Danke-Seite

## Entwicklung
Die Seite besteht aus statischem HTML, CSS und JavaScript. Öffne einfach `index.html` in einem Browser, um sie anzuzeigen.

## Deployment (Netlify)
1. Lade die Dateien `index.html`, `danke.html`, `style.css` und `script.js` in ein leeres Netlify-Projekt.
2. Stelle sicher, dass das Formular aktiv ist (Netlify erkennt es automatisch über `data-netlify="true"`).
3. Optional: Passe die E-Mail-Adresse im Kontaktbereich an deine Schule an.
